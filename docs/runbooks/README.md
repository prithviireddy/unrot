| Runbook | Use it when |
|---|---|
| [capture-inspector-dumps.md](capture-inspector-dumps.md) | Writing or fixing detection rules from what's actually on screen |
| [publish-rules-update.md](publish-rules-update.md) | Changing `rules.json` and getting it to phones |
| [roll-back-rules.md](roll-back-rules.md) | A published rules file is blocking the wrong thing or missing reels |
| [ship-build-to-testers.md](ship-build-to-testers.md) | Getting an APK onto your own or a tester's phone |
